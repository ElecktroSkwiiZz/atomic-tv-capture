# Politique de confidentialité — ATOMIC TV Capture

**Éditeur : JB Atomic Industries** · https://jbatomic.com/ · Novembre 2026.

- L'application ne nécessite pas de compte utilisateur.
- Les images PNG et vidéos MP4 sont stockées localement dans le répertoire privé de l'application, sur la télévision.
- Le service d'accessibilité écoute les événements de touches nécessaires aux raccourcis et utilise l'API de capture système. Il ne collecte ni le contenu textuel des applications ni les données de saisie.
- Le serveur web local est destiné au transfert et au contrôle via un navigateur sur le même réseau. Les échanges HTTP **ne sont pas chiffrés** : ne l'exposez pas sur Internet ou un réseau non fiable. Le serveur utilise un code à 4 chiffres, des limites de tentatives, une session et des protections contre les requêtes intersites.
- Les captures et vidéos peuvent être supprimées individuellement ou en totalité depuis l'application et le tableau de bord PC.
- Les vérifications de mise à jour communiquent avec GitHub (`api.github.com` et `github.com`), qui reçoit les informations techniques habituelles d'une requête Internet telles que l'adresse IP publique. Aucune capture n'est envoyée à GitHub par cette fonctionnalité.
- Aucun outil d'analytique, de publicité ou de suivi comportemental n'est inclus dans les sources fournies.

Contact et informations : https://jbatomic.com/.
